# Front-end_Project
This project combines three separate web pages:

#Tribute Page: A tribute page dedicated to Dr. A.P.J. Abdul Kalam, the 11th President of India, and an aerospace scientist.

#Technical Documentation: A demonstration of how to create a technical documentation page using HTML and CSS, featuring topics like JavaScript, Java, HTML, CSS, and Media Queries.

#Lifeline Bloodbank Form: A survey form that collects personal information, blood group, previous donation history, and health-related details for potential blood donors.

These pages are developed using basic HTML, CSS, and minimal JavaScript.

Pages Included
1. Tribute Page
Purpose: A tribute to Dr. A.P.J. Abdul Kalam, highlighting his life, work, and contributions to science and India.

Features:

Image of Dr. Kalam with a caption.

Detailed biography and significant achievements.

A link to his Wikipedia page for more information.

2. Technical Documentation
Purpose: To display technical documentation in a clean, organized way.

Features:

A navigation bar for easy access to different sections.

Sections that explain key topics like JavaScript, Java, HTML, CSS, and Media Queries.

Smooth scrolling navigation to jump between sections when clicked.

3. Lifeline Bloodbank Form
Purpose: A survey form designed to collect information from potential blood donors.

Features:

Collects user details such as name, email, contact number, and blood group.

Options to select previous donation history.

Health-related checkboxes to indicate any diseases the donor may have suffered from.

A textarea to leave comments or suggestions.

A submit button for submission (note: no backend functionality yet).

Technologies Used
HTML: Used to structure content and form elements.

CSS: External styling applied for visual design and layout.

JavaScript: Included for smooth scrolling in the Technical Documentation page.

How to Use
Clone the Repository:

Clone the repository to your local machine using git clone <repository_url>, or download the ZIP file.

Open the Files:

Open index.html in any modern web browser to view the Tribute Page.

Open technical-docs.html for the Technical Documentation page.

Open survey-form.html for the Lifeline Bloodbank Form.

Viewing and Interacting:

For the Tribute Page, simply view the biography and click on the provided link to read more about Dr. A.P.J. Abdul Kalam.

For the Technical Documentation page, use the navigation bar to scroll between different sections and learn about the web technologies.

For the Lifeline Bloodbank Form, fill out the form with your details and submit (currently no backend connected).
